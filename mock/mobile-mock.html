Catatan desain & implementasi

🧭 Bottom tab bar

Ganti sidebar desktop. 5 slot: Home · My Work · Tasks · Issues · Menu. Slot "Menu" buka bottom sheet berisi Reporting, Teams, Settings, Users (admin), tema, logout. Gantikan SidebarTrigger yang sekarang nggak pernah dipakai.

📋 List-first, bukan tabel

Di <md, DataTable dirender jadi kartu (title, ID, status, priority, assignee, due). Tetap ada search + filter chip. Tabel tetap dipakai di desktop. Zero horizontal-scroll di HP.

📱 Detail full-screen

TaskDetail jadi layar penuh: header back + judul + status, checklist, detail collapsible, komentar, lalu action bar sticky di bawah (Start / Complete / Cancel). Panel "Details" 320px desktop jadi accordion di HP.

🖐️ Touch & safe-area

Semua target ≥44px (sekarang h-9=36px). Pakai env(safe-area-inset-bottom) buat iPhone home-bar & Android gesture bar — makanya tab bar iPhone 78px vs Android 66px. viewport-fit=cover wajib ditambah di index.html.

📸 Evidence kamera

Ini app operator lapangan: FileUploadDialog tambah capture="environment" biar langsung buka kamera HP, bukan cuma file picker. Foto otomatis ke Google Drive lewat Edge Function yang sudah ada.

🎯 Prioritas implementasi

1) Tab bar + routing mobile → 2) card list Tasks/MyWork → 3) detail full-screen → 4) bottom sheet Menu → 5) FAB new task → 6) safe-area + touch target → 7) (opsional) PWA manifest.
